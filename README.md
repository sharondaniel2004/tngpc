# 🛒 Tamil Nadu Police Canteen App

### 🚀 **Streamlining Grocery Shopping for Police Personnel**

The **Tamil Nadu Police Canteen App** is a **mobile application** built using **Flutter (Dart)** and **MongoDB**, designed to simplify and modernize the grocery shopping experience for Tamil Nadu Police personnel. The app offers a seamless online shopping experience, complete with real-time order updates, secure payments, and an intuitive admin panel for efficient canteen management.

---

## 📱 Features

### **For Users**

- **Profile Creation**: Users can create and manage profiles to personalize their shopping experience.
- **Product Catalogue**: Browse a wide range of products available in the canteen.
- **Shopping Cart**: Add items to the cart with ease and review before checkout.
- **Secure Payments**: Integrated payment gateway for smooth and secure online transactions.
- **Order Tracking**: Receive real-time notifications about the order status — from placement to preparation.
- **Order History**: Convenient access to previous orders for easy reordering.

### **For Admin (Canteen Workers)**

- **Admin Panel**: An easy-to-use interface for canteen workers to manage and track orders.
- **Inventory Management**: Keep track of available stock and product levels.
- **Pickup Confirmation**: Admins can confirm when an order is ready for pickup.
- **Feedback Mechanism**: Receive feedback from users to improve service quality.

### **Security**

- **Data Encryption**: All sensitive data is securely stored using encryption.
- **Login Security**: Strong authentication measures to protect user profiles and sensitive information.

---

## 🛠️ Tech Stack

- **Frontend**: Flutter (Dart) for cross-platform mobile app development
- **Backend**: MongoDB for scalable data storage
- **Authentication**: Secure user login and registration
- **Payment Integration**: Smooth, secure online transactions (e.g., Razorpay, Stripe)
- **Admin Panel**: For canteen workers to manage inventory and orders efficiently

## 💡 Installation

### **Prerequisites**

- [Flutter](https://flutter.dev/docs/get-started/install) installed on your system.
- [MongoDB](https://www.mongodb.com/) instance (either local or cloud).
- Payment gateway credentials (for integration with Razorpay/Stripe).

### **Steps**

1. Clone this repository:

   ```bash
   git clone https://github.com/Sharondanniel2004/tamil-nadu-police-canteen-app.git

   ```

2. Install dependencies:

- flutter pub get

3. Set up your MongoDB database and update the connection details in the lib/services/db_service.dart file.

4. Run the app on your preferred device:

###### flutter run
